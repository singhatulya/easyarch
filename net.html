Connecting to The Internet

Connecting to the Internet is very essential for Arch Linux Installation

If you are on Ethernet, Chances are you may already be Connected to the Internet.
You check by-

ping 8.8.8.8

Or

ping google.com

If you Recieve Packets then you are good to go!

If you are not able to get packets, You should use Wifi.

Continue- Partitioning the Disks

Steps for connecting using Wifi.

Step 1 Run:

iwctl

Type the exact name of your Preferred Device name below.

Then Run this Command to get a list of all Networks.

station ?? scan

Then

station ?? get-networks
station ?? connect ???

After all these steps. Check Internet by running the following command.

ping 8.8.8.8

If you recieve packets, You are good to go.
