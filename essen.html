Essentials

Now we have chrooted into the system, and before doing anything, we should install some very critical things.

Install sudo.

Install sudo for security of the system. Very important. Just run:

pacman -S sudo

useradd -m -G wheel -s /bin/bash user

Then we will put a password on it. Run:

passwd yourusername

Allow sudo to work on wheel group.

EDITOR=nano visudo

find and uncomment:

%wheel ALL=(ALL:ALL) ALL

Set your Timezone

Just run:

ln -sf /usr/share/zoneinfo/Asia/Kolkata /etc/localtime hwclock --systohc

You may want to replace Asia/Kolkata with your own Timezone

Then go for hostname.

Run:

echo archpc > /etc/hostname

Installing the essentials.

Now run, important for UEFI systems.:

pacman -S grub efibootmgr networkmanager

Then install CPU microcode. For intel:

pacman -S intel-ucode

For AMD:

pacman -S amd-ucode

Enable Networking

systemctl enable NetworkManager

Install GRUB

GRUB lets you choose the operating system and options before boot. Just Run:

grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB

grub-mkconfig -o /boot/grub/grub.cfg

Reboot

Just run:

exit && reboot

Remove your installation media. And boot from the Arch SSD.
