Using cfdisk to Partition the Disks

Follow the following steps for UEFI to finally load Base Arch Linux on your Partition

First Run to see all disks:

lsblk

Write your preferred disk name, add a p as a suffix IF using nvme drives.

Run:

sudo cfdisk ??

Then Select GPT for your system.

Since this guide is for UEFI systems, first go to Select Free space and select [New] and create 512M Partition and set Type as UEFI Filesystem. This will be used by your UEFI BIOS to load the Operating System.

Select Remaining Space and set it as Linux Filesystem.

Then, Select Write and type in yes.

Run:

mkfs.fat -F32 ??

Then run:

mkfs.ext4 ??

And with that You have successfully partitioned the system.
Next is actually putting Arch onto the System.

Run:

mount ?? /mnt
mkdir -p /mnt/boot/efi mount ?? /mnt/boot/efi

Now we can run the following commands:

pacstrap -K /mnt base linux linux-firmware
genfstab -U /mnt >> /mnt/etc/fstab
arch-chroot /mnt

With the last command, you are no longer in Live archiso, Now you are in your Operating System. But it doesn't have anything other than Base Arch.
