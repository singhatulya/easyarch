Installing KDE

Update the whole system

pacman -Syu

Install KDE, Applications and sddm

Then we can install the Plasma DE , applications and sddm(a login manager)

pacman -S plasma kde-applications sddm

Activating sddm

systemctl enable sddm.service

Installing Drivers

For intel:

pacman -S mesa

For AMD:

pacman -S mesa xf86-video-amdgpu

For Nvidia:

pacman -S nvidia nvidia-utils

Just Run as the final command for your installation:

exit && reboot

Once you boot in, You will see your sddm login prompt and this means that your installation is officially..

Completed 🎉
