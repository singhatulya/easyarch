GNOME Installation

Getting GNOME packages

Run:

pacman -Syu gnome gdm

Enable the Display Manager

systemctl enable gdm

Installing Drivers

For intel:

pacman -S mesa intel-media-driver

For AMD:

pacman -S mesa vulkan-radeon

For Nvidia:

pacman -S nvidia nvidia-utils

Done

Just Run as the final command for your installation:

exit && reboot
